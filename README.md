# ashencroft-hyperautomation.github.io

Public website for **Ullr**, an Android app that keeps archery records and scores your arrows from a photo of the target.

- English: https://ashencroft-hyperautomation.github.io/ullr/
- Français : https://ashencroft-hyperautomation.github.io/ullr/fr/

The `ullr/` folder holds the site's sources (MkDocs Material). They are published here from the app's own repository; edit them there, not here. The `Pages` workflow builds and deploys the site on every push.
