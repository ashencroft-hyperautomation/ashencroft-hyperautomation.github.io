# ashencroft-hyperautomation.github.io

Public website for **sagitt·AI·re** (formerly Ullr), an Android app that keeps archery records and scores your arrows from a photo of the target.

- English: https://ashencroft-hyperautomation.github.io/sagittaire/
- Français : https://ashencroft-hyperautomation.github.io/sagittaire/fr/
- Deutsch: https://ashencroft-hyperautomation.github.io/sagittaire/de/
- Español: https://ashencroft-hyperautomation.github.io/sagittaire/es/

The `sagittaire/` folder holds the site's sources (MkDocs Material). They are published here from the app's own repository; edit them there, not here. The `Pages` workflow builds and deploys the site on every push, and writes a redirect at every old `/ullr/` address.
