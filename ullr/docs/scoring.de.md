# Drei Arten zu werten { #three-ways-to-score }

Ullr wertet eine Passe auf eine von drei Arten. Du wählst unter **Einstellungen → Wertungsmethode** und kannst jederzeit wechseln: Frühere Einheiten behalten ihre Ergebnisse.

![Die Seite Wertungsmethode: was jede Methode macht, dann die Wahl zwischen deinem eigenen API-Schlüssel, Teilen mit deiner KI-App und von Hand.](images/screenshots/settings.png){ .shot width="240" }

| | [Dein eigener API-Schlüssel](scoring-api.md) | [Mit deiner KI-App teilen](scoring-share.md) | [Von Hand](scoring-manual.md) |
|---|---|---|---|
| **In der App** | Dein eigener API-Schlüssel (automatisch) | Mit deiner KI-App teilen | Von Hand (ohne KI) |
| **Du brauchst** | Einen Schlüssel von einem KI-Dienst | Eine KI-App auf deinem Handy | Nichts |
| **Nach dem Foto** | Im Hintergrund gewertet, ein paar Sekunden später bereit zum Prüfen | Du teilst, die KI-App antwortet, du fügst die Antwort ein | Du tippst im Foto auf jeden Pfeil und wählst seinen Ring |
| **Unsichere Pfeile eingekreist** | Ja | Ja | Du bestimmst jeden Ring selbst |
| **Ohne Empfang** | Wartet auf das Netz | Braucht das Netz der KI-App | Funktioniert überall |
| **Was das Handy verlässt** | Das Foto, deine Einstellungen und dein Schlüssel, nur an diesen Dienst | Das Foto und der Prompt, von dir geteilt | Nichts |
| **Kosten** | Ein paar Cent pro Passe, über dein Konto beim Dienst | Was deine KI-App dich kostet | Kostenlos |

**Von Hand werten geht immer.** Egal welche Methode: Jede Passe lässt sich von Hand werten, mit **Stattdessen von Hand werten**, während du wartest oder nach einer fehlgeschlagenen Wertung.

## Welche passt? { #which-one }

- **Du willst es automatisch** und hast nichts gegen ein paar Cent pro Passe: [dein eigener API-Schlüssel](scoring-api.md).
- **Du zahlst schon für eine KI-Chat-App** und willst keinen API-Schlüssel: [mit deiner KI-App teilen](scoring-share.md).
- **Du willst gar keine KI**, oder du schießt dort, wo es keinen Empfang gibt: [von Hand](scoring-manual.md). Das Foto bleibt nützlich: Du setzt deine Pfeile darauf, und es bleibt der Beweis.
