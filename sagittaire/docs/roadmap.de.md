# Roadmap { #roadmap }

sagitt·AI·re ist ein Pro-bono-Projekt von Ashencroft Studio und wird offen entwickelt. Hier steht es gerade.

## Erledigt { #done }

- [x] Einheiten mit jedem Bogen, jeder Auflage, beliebig vielen Auflagen auf der Scheibe und Pfeilen pro Passe, auch mit zwei Dreifach-Auflagen gleichzeitig
- [x] KI-Wertung anhand eines Fotos, mit eingekreisten unsicheren Pfeilen und Korrektur mit einem Tipp
- [x] Die Linienregel und deine Wertungsregel (X = 10, Innenzehn, X = 11) werden der KI mit jedem Foto erklärt
- [x] Der KI-Dienst deiner Wahl (Anthropic, Google, OpenAI oder jeder OpenAI-kompatible Dienst unter deiner eigenen Adresse), mit deinem eigenen Schlüssel
- [x] Werten ohne Schlüssel: Teile das Foto mit der KI-App auf deinem Handy und füge ihre Antwort ein
- [x] Nutzungsbedingungen und Datenschutzerklärung auf Französisch und Englisch, beim ersten Start akzeptiert, mit den Open-Source-Lizenzen, unter Einstellungen → Info und Rechtliches
- [x] Daten löschen (alle Einheiten oder alles), und Erfahrung und Abzeichen an der Trophäenwand zurücksetzen
- [x] Gespeicherte Orte umbenennen, zusammenführen und löschen, ohne eine Einheit zu verlieren
- [x] Wertung von Hand, ohne KI: Tippe im Foto auf jeden Pfeil und wähle seinen Ring, oder tippe die Ergebnisse ohne Foto ein
- [x] Wertung von Hand: Markiere die Scheibe einmal, dann zählen von Hand gesetzte Pfeile in **Wo sich deine Pfeile gruppieren** und in der Heatmap
- [x] Funktioniert ohne Empfang: Fotos werden gespeichert und später gewertet, oder von Hand gewertet
- [x] Übersicht, Verlauf, Schießzettel und Diagramm der Ergebnisse pro Passe
- [x] Bögen, mit einem Katalog aktueller Compoundbögen, Zuggewicht und Auszugslänge
- [x] Englisch, Französisch, Deutsch und Spanisch
- [x] Deutsch und Spanisch in der App, mit übersetzten Nutzungsbedingungen und Datenschutzerklärung (und jetzt ist auch diese Website auf Englisch, Französisch, Deutsch und Spanisch)
- [x] Datenschutz von Anfang an: Fotos auf die Scheibe zugeschnitten, versteckte Daten entfernt, nichts über dich oder dein Handy gesendet
- [x] sagitt·AI·re Demo, mit sechs Monaten Beispiel-Einheiten, um jeden Bildschirm auszuprobieren
- [x] Bogentypen nach den Bogenklassen von World Archery (Blankbogen, Recurve, Compound) und die Disziplin jeder Einheit (Scheiben-, Feld-, 3D- oder Para-Bogenschießen)
- [x] Drei Designs: Original, Tag am Platz (für Sonnenlicht) und Nacht am Platz (für die Halle), mit Ergebnissen in ihren Ringfarben
- [x] Spielmodus (Vorschau): die Halle und der Bogenplatz in Pixel-Art, geh zu einem Ort, um ihn zu öffnen, dein eigener Schütze, Begleiter, Musik und Geräusche, und jeder Bildschirm im Spiel-Look; deine Statistik an der Feuerstelle, die Passe zum Prüfen am Pfeilständer, und Stufen, Abzeichen und Trophäen, die du dir durch echtes Schießen verdienst

## Geplant { #coming }

- [x] **Spielmodus:** Outfits und Hallendekorationen, verdient durch Stufen und Abzeichen, eine Belohnung für jedes Abzeichen (ein Köcher, ein Lorbeerkranz, ein silberner Umhang, ein Federhut, eine Eule als Begleiter, eine bemalte Scheibe und gekreuzte Pfeile), ein Kriegshorn für eine persönliche Bestleistung und der Bogenplatz in vier Jahreszeiten

- [x] **Deine Daten, wie du willst:** Export (alles, nur Daten oder nur Fotos) in einen Ordner deiner Wahl, Wiederherstellen auf demselben oder einem neuen Handy, und Speicher freigeben, indem du alte Fotos entfernst
- [x] Eine Zusammenfassung der Einheit teilen, als Text oder mit einem Bild des Schießzettels
- [x] Statistik: Schnitt im Zeitverlauf, Umfang, Verteilung der Ergebnisse, Konstanz, Ermüdung im Lauf einer Einheit, wo sich deine Pfeile gruppieren, Bestwerte pro Runde
- [x] Persönliche Bestleistungen pro Rundentyp (zum Beispiel 18 m, 60 Pfeile), auf der Übersicht und bei jeder Einheit
- [x] Statistik nach Entfernung und Auflage, und eine Heatmap pro Spot
- [x] Kleinere Markierungen, wo Pfeile dicht beieinander stecken
- [x] **Wertungsproblem melden:** eine E-Mail zur Passe, an wen du willst, mit dem Foto nur, wenn du es anhängst
- [x] **Visiermarken** pro Bogen und Entfernung, an der Schießlinie angezeigt
- [x] **Pfeilsätze** und ein **Tuning-Logbuch** für jeden Bogen, mit den Tuning-Änderungen im Statistik-Verlauf
- [x] **Trainingsziele:** Pfeile pro Woche und ein Schnitt, den du erreichen willst, auf der Übersicht, und eine Wochenherausforderung im Spielmodus
- [x] Eine Prüfung der Barrierefreiheit auf jedem Bildschirm (große Schrift, Screenreader)
- [ ] KI-Wertung auf Feld- und 3D-Auflagen geprüft
